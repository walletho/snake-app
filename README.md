# Snake App

Kleine Snake-Web-App ohne Build-Tooling. Die Dateien koennen direkt im Browser geoeffnet werden.

## Start

1. Wechsle in das Projekt:
   `cd /home/wallth/snake-app`
2. Oeffne `index.html` im Browser.

## Dateien

- `index.html`: Layout und Struktur
- `styles.css`: Styling und responsive Layouts
- `script.js`: Spiellogik, Eingaben, Score und Highscore
